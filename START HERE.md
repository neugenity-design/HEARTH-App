# Open Hearth

Double-click **Hearth.pyw**. Windows may display it simply as **Hearth** when file extensions are hidden. It starts Hearth locally and opens your main workspace in the browser.

Your main workspace contains the data imported from your TenantCloud export, including the separately verified rent-payment attachments. It does not load the fictional preview records.

If the browser does not open automatically, visit http://127.0.0.1:8768/ while Hearth is running.

Use **Hearth Tools.pyw** when you need to restore a full Hearth backup into a separate workspace.

The application files are in this `hearth` folder. Your working database and uploaded files are under `data`; use Hearth's **Download full backup** control rather than copying a live database by hand.
